
 JDK 8
 Database Oracle 10g
 First run Oracle.java file then Login.java


## How to Run

1. Make sure Oracle 10g is installed and the database is running.  
2. Compile and run the `Oracle.java` file to initialize the database connection.  
3. Then, run the `Login.java` file to start the application.

## Features

- Translate English words to Hindi.  
- Simple and intuitive GUI using Java Swing.  
- Login system to manage access.  
- Data stored and fetched from Oracle database.
